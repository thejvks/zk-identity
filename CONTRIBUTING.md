# Contributing to ZK-Identity

Thanks for your interest in contributing!

## Getting Started

1. Fork the repo and clone your fork
2. `npm install`
3. `npx hardhat compile` to compile contracts
4. `npx hardhat test` to run the test suite

## Areas We Need Help

- Additional Circom circuits (new credential types)
- Improved AI reputation signals
- zkSync Era deployment and testing
- Mobile wallet support
- Frontend improvements

## Pull Requests

- Create a feature branch from `main`
- Keep PRs focused — one feature or fix per PR
- Make sure `npx hardhat test` passes before submitting
- Add tests for new contract functionality

## Reporting Issues

Open a GitHub issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
